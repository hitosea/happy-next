The sessions screen is the heart of the Happy app. It shows your active sessions across all your machines, grouped by machine.

## Viewing sessions

The home screen lists your active sessions, grouped by machine. Each session card shows:

- The agent type (Claude, Codex, Gemini, or Qoder)
- The model being used
- The working directory
- A preview of the latest message
- An unread indicator for new messages

Tap a session to open it.

### Tabs

When you have sessions on more than one machine — or any shared sessions — a tab bar appears above the list:

- **All** — every session; always the first tab
- **One tab per machine** — filter to a single machine's sessions
- **Shared with me** / **Shared by me** — shown only when you have shared sessions

A colored dot on a machine tab flags what needs attention there: **orange** = a session is waiting on a permission decision, **pulsing blue** = a session is actively working, **solid blue** = an unread completed response. The **All** tab never shows a dot.

With a single machine and no shared sessions, no tab bar is shown — you just see the list.

## Sending messages

In a session, type a message at the bottom of the screen and send it. The message is delivered to the AI agent running on your machine. You'll see the agent's response in real time.

You can also:
- **Attach images** — Tap the image icon to send screenshots or photos, with or without accompanying text
- **Paste from clipboard** — Long-press the input field to paste

## Creating a new session

Tap the **+** button on the home screen — or the new-session button in an open session's header — to create a new session. You can configure:

- **Machine** — Which computer to run the session on
- **Agent** — Claude, Codex, Gemini, or Qoder
- **Model** — The specific model to use
- **Working directory** — The project folder on your machine
- **Permission mode** — How the agent handles permission requests

The initial message is optional — you can create the session without typing anything and start interacting once it's running.

<Info>
Creating a session from the app requires the daemon to be running on the target machine. See [Daemon](/cli/daemon).
</Info>

## Session actions

Long-press a session card or use the session menu for additional actions:

- **Duplicate** — Create a copy of the session with the same configuration
- **Fork** — Start a new session from a specific point in the conversation
- **Resume** — Resume an ended session
- **Delete** — Remove the session permanently

## Pending queue

If the agent is busy processing a previous message, your new messages are queued and dispatched automatically when the agent is ready.

Tap a queued message to open it, where you can:

- **Edit** it before it's sent — editing pauses the message so it isn't dispatched mid-change
- **Pause / Resume** — pausing turns the message into a **draft**: it stays in the queue and syncs across your devices, but is skipped by auto-dispatch until you resume or send it
- **Send now** — dispatch it immediately, ahead of the queue
- **Pin** — move an active message to the top of the queue
- **Copy** or **Delete**

Active messages sit at the top in send order (pinned first); paused drafts sink to the bottom.
