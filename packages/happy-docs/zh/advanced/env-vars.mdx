## CLI

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `HAPPY_SERVER_URL` | `https://api.happy-next.com` | Happy 服务器 API 端点 |
| `HAPPY_WEBAPP_URL` | `https://app.happy-next.com` | Happy Web 应用 URL |
| `HAPPY_HOME_DIR` | `~/.happy-next` | 本地数据目录 |
| `HAPPY_VARIANT` | `stable` | `stable` 或 `dev`（并行运行两个版本） |
| `HAPPY_EXPERIMENTAL` | — | 启用实验性功能（`true`/`1`/`yes`） |
| `HAPPY_DISABLE_CAFFEINATE` | — | 禁用 macOS 睡眠阻止 |
| `HAPPY_EXTRA_MCP_SERVERS` | — | 附加 MCP 服务器（JSON） |
| `GEMINI_MODEL` | — | 覆盖默认 Gemini 模型 |
| `GOOGLE_CLOUD_PROJECT` | — | Google Cloud 项目 ID（Workspace 账户） |
| `HAPPY_QODER_PATH` | `qoder` | 指定 Happy 启动哪个 `qoder` 可执行文件 |
| `HAPPY_QODER_MODEL` | — | 新建 Qoder 会话时使用的模型 id（`qoder-auto`，或 `qoder --list-models` 列出的任意 id） |

## 服务器

### 必需

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `DATABASE_URL` | — | PostgreSQL 连接字符串 |
| `HANDY_MASTER_SECRET` | — | 主加密密钥（64 个字符以上） |
| `PORT` | `3005` | HTTP 服务器端口 |

### 可选

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `NODE_ENV` | `development` | `development` 或 `production` |
| `REDIS_URL` | — | Redis 连接字符串 |
| `APP_URL` | — | 公共服务器 URL |
| `PUBLIC_API_BASE_URL` | — | 通过 `/v1/app-config` 向客户端公布的 API 基础 URL，用于服务发现 |
| `METRICS_ENABLED` | `false` | 启用 Prometheus 指标 |
| `METRICS_PORT` | `9090` | 指标端点端口 |

### 文件存储（S3/MinIO）

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `S3_HOST` | — | S3 主机名 |
| `S3_PORT` | — | S3 端口 |
| `S3_USE_SSL` | `false` | 对 S3 使用 HTTPS |
| `S3_ACCESS_KEY` | — | S3 访问密钥 |
| `S3_SECRET_KEY` | — | S3 秘密密钥 |
| `S3_BUCKET` | — | S3 存储桶名称 |
| `S3_PUBLIC_URL` | — | 上传文件的公共 URL |

### GitHub OAuth

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `GITHUB_CLIENT_ID` | — | OAuth App 客户端 ID（不是 GitHub App） |
| `GITHUB_CLIENT_SECRET` | — | OAuth App 客户端密钥 |
| `GITHUB_REDIRECT_URL` | — | OAuth 回调 URL |
| `GITHUB_WEBHOOK_SECRET` | — | 可选仓库 webhook 签名密钥，与 OAuth 授权独立 |

### 语音

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `VOICE_TOOL_BRIDGE_KEY` | — | 语音工具桥接授权密钥 |

## 语音网关（happy-voice）

### 管线

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `VOLC_ASR_RESOURCE_ID` | `volc.seedasr.sauc.duration` | 语音转文字（ASR）资源 ID |
| `VOLC_ASR_STREAM_MODE` | `2` | ASR 流式模式 |
| `DOUBAO_MODEL` | `doubao-seed-2-0-lite-260428` | 语音代理 LLM（豆包） |
| `VOLC_TTS_VOICE` | `zh_female_vv_uranus_bigtts` | TTS 音色/发音人 |
| `VOLC_AGENT_TTS_RESOURCE_ID` | `seed-tts-2.0` | 实时代理 TTS 资源 ID |
| `AGENT_WELCOME_MESSAGE` | — | 自定义欢迎消息 |

### RTC（火山引擎）

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `VOLC_RTC_APP_ID` | — | 火山引擎 RTC 应用 ID（必需） |
| `VOLC_RTC_APP_KEY` | — | 火山引擎 RTC 应用密钥（必需） |
| `VOLC_ACCESS_KEY_ID` | — | 火山引擎 IAM 访问密钥 ID（必需） |
| `VOLC_SECRET_ACCESS_KEY` | — | 火山引擎 IAM 秘密访问密钥（必需） |
| `VOLC_RTC_REGION` | `cn-north-1` | RTC 区域 |
| `VOLC_RTC_API_VERSION` | `2025-06-01` | RTC OpenAPI 版本 |
| `RTC_TOKEN_TTL_SECONDS` | `86400` | 房间加入令牌有效期 |

### 服务器

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `HOST` | `0.0.0.0` | API 服务器主机 |
| `PORT` | `3040` | API 服务器端口 |
| `VOICE_AUTH_SECRET` | — | API 授权密钥（32 个字符以上，必需） |

### 语音调优

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `VOLC_ASR_SILENCE_MS` | `600` | 语音结束前的静默时间（VAD） |
| `LLM_HISTORY_LENGTH` | `10` | 保留的对话历史轮数 |
| `LLM_TEMPERATURE` | `0.1` | LLM 采样温度 |
| `LLM_TOP_P` | `0.3` | LLM 核采样 |
| `LLM_MAX_TOKENS` | `512` | LLM 最大响应 token 数 |

## 应用

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `APP_ENV` | — | `development`、`preview` 或 `production` |
| `EXPO_PUBLIC_POSTHOG_KEY` | — | PostHog 分析密钥 |
| `EXPO_PUBLIC_VOICE_TOOL_BRIDGE_BASE_URL` | — | 语音工具桥接基础 URL（默认使用服务器 URL） |
