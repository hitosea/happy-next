## 创建运行

```
POST /v1/orchestrator/submit
```

创建一个包含任务的新编排器运行。

**请求体：**

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `title` | string | 运行标题（必填） |
| `tasks` | array | 任务定义数组（1–32 个） |
| `tasks[].taskKey` | string | 稳定的键，供其他任务的 `dependsOn` 引用本任务 |
| `tasks[].title` | string | 任务标题 |
| `tasks[].provider` | string | `claude`、`codex`、`gemini` 或 `qoder` |
| `tasks[].model` | string | 模型标识符 |
| `tasks[].prompt` | string | 任务提示/指令（必填） |
| `tasks[].workingDirectory` | string | 工作目录路径 |
| `tasks[].dependsOn` | array | 前置任务的 `taskKey` 值 |
| `tasks[].retry` | object | `{ maxAttempts, backoffMs }` 重试策略 |
| `tasks[].target` | object | `{ type: "current_machine" \| "machine_id", machineId }` |
| `maxConcurrency` | number | 并行运行的最大任务数（1–8） |
| `mode` | string | `blocking` 或 `async` |
| `idempotencyKey` | string | 对重复提交去重 |

## 列出运行

```
GET /v1/orchestrator/runs
```

列出已认证用户的编排器运行。

## 获取运行

```
GET /v1/orchestrator/runs/:runId
```

获取特定运行的详情，包括所有任务及其状态。

**响应：**

```json
{
  "id": "clx...",
  "status": "running",
  "tasks": [
    {
      "id": "clx...",
      "prompt": "Set up database schema",
      "provider": "claude",
      "model": "claude-sonnet-4-6",
      "status": "completed",
      "dependsOn": []
    },
    {
      "id": "clx...",
      "prompt": "Write API endpoints",
      "provider": "claude",
      "model": "claude-sonnet-4-6",
      "status": "running",
      "dependsOn": ["setup-db"]
    }
  ]
}
```

## 取消运行

```
POST /v1/orchestrator/runs/:runId/cancel
```

取消正在进行的编排器运行。

## 轮询完成状态

```
GET /v1/orchestrator/runs/:runId/pend
```

长轮询等待运行完成或状态变更。

**查询参数：**

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `cursor` | string | 上一次响应返回的游标；当状态相对该游标发生变化时返回 |
| `waitFor` | string | `change`（默认）或 `terminal` |
| `timeoutMs` | number | 长轮询超时，0–120000（默认 30000） |
| `include` | string | `summary`（默认）或 `all_tasks` |
