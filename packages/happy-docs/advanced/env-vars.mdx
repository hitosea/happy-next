## CLI

| Variable | Default | Description |
|----------|---------|-------------|
| `HAPPY_SERVER_URL` | `https://api.happy-next.com` | Happy server API endpoint |
| `HAPPY_WEBAPP_URL` | `https://app.happy-next.com` | Happy web app URL |
| `HAPPY_HOME_DIR` | `~/.happy-next` | Local data directory |
| `HAPPY_VARIANT` | `stable` | `stable` or `dev` (run both versions side-by-side) |
| `HAPPY_EXPERIMENTAL` | — | Enable experimental features (`true`/`1`/`yes`) |
| `HAPPY_DISABLE_CAFFEINATE` | — | Disable macOS sleep prevention |
| `HAPPY_EXTRA_MCP_SERVERS` | — | Additional MCP servers (JSON) |
| `GEMINI_MODEL` | — | Override default Gemini model |
| `GOOGLE_CLOUD_PROJECT` | — | Google Cloud Project ID (Workspace accounts) |
| `HAPPY_QODER_PATH` | `qoder` | Which `qoder` executable Happy spawns |
| `HAPPY_QODER_MODEL` | — | Model to seed a new Qoder session with, by id (`qoder-auto`, or any id from `qoder --list-models`) |

## Server

### Required

| Variable | Default | Description |
|----------|---------|-------------|
| `DATABASE_URL` | — | PostgreSQL connection string |
| `HANDY_MASTER_SECRET` | — | Master encryption key (64+ characters) |
| `PORT` | `3005` | HTTP server port |

### Optional

| Variable | Default | Description |
|----------|---------|-------------|
| `NODE_ENV` | `development` | `development` or `production` |
| `REDIS_URL` | — | Redis connection string |
| `APP_URL` | — | Public server URL |
| `PUBLIC_API_BASE_URL` | — | API base URL advertised to clients via `/v1/app-config` for service discovery |
| `METRICS_ENABLED` | `false` | Enable Prometheus metrics |
| `METRICS_PORT` | `9090` | Metrics endpoint port |

### File Storage (S3/MinIO)

| Variable | Default | Description |
|----------|---------|-------------|
| `S3_HOST` | — | S3 hostname |
| `S3_PORT` | — | S3 port |
| `S3_USE_SSL` | `false` | Use HTTPS for S3 |
| `S3_ACCESS_KEY` | — | S3 access key |
| `S3_SECRET_KEY` | — | S3 secret key |
| `S3_BUCKET` | — | S3 bucket name |
| `S3_PUBLIC_URL` | — | Public URL for uploaded files |

### GitHub OAuth

| Variable | Default | Description |
|----------|---------|-------------|
| `GITHUB_CLIENT_ID` | — | OAuth App Client ID (not GitHub App) |
| `GITHUB_CLIENT_SECRET` | — | OAuth App Client Secret |
| `GITHUB_REDIRECT_URL` | — | OAuth callback URL |
| `GITHUB_WEBHOOK_SECRET` | — | Optional repository webhook signature secret; independent of OAuth |

### Voice

| Variable | Default | Description |
|----------|---------|-------------|
| `VOICE_TOOL_BRIDGE_KEY` | — | Voice tool bridge authorization key |

## Voice Gateway (happy-voice)

### Pipeline

| Variable | Default | Description |
|----------|---------|-------------|
| `VOLC_ASR_RESOURCE_ID` | `volc.seedasr.sauc.duration` | Speech-to-text (ASR) resource ID |
| `VOLC_ASR_STREAM_MODE` | `2` | ASR streaming mode |
| `DOUBAO_MODEL` | `doubao-seed-2-0-lite-260428` | Voice agent LLM (Doubao) |
| `VOLC_TTS_VOICE` | `zh_female_vv_uranus_bigtts` | TTS voice/speaker |
| `VOLC_AGENT_TTS_RESOURCE_ID` | `seed-tts-2.0` | Live-agent TTS resource ID |
| `AGENT_WELCOME_MESSAGE` | — | Custom greeting message |

### RTC (Volcengine)

| Variable | Default | Description |
|----------|---------|-------------|
| `VOLC_RTC_APP_ID` | — | Volcengine RTC app ID (required) |
| `VOLC_RTC_APP_KEY` | — | Volcengine RTC app key (required) |
| `VOLC_ACCESS_KEY_ID` | — | Volcengine IAM access key ID (required) |
| `VOLC_SECRET_ACCESS_KEY` | — | Volcengine IAM secret access key (required) |
| `VOLC_RTC_REGION` | `cn-north-1` | RTC region |
| `VOLC_RTC_API_VERSION` | `2025-06-01` | RTC OpenAPI version |
| `RTC_TOKEN_TTL_SECONDS` | `86400` | Room join token lifetime |

### Server

| Variable | Default | Description |
|----------|---------|-------------|
| `HOST` | `0.0.0.0` | API server host |
| `PORT` | `3040` | API server port |
| `VOICE_AUTH_SECRET` | — | API authorization secret (32+ characters, required) |

### Speech Tuning

| Variable | Default | Description |
|----------|---------|-------------|
| `VOLC_ASR_SILENCE_MS` | `600` | Silence before end-of-utterance (VAD) |
| `LLM_HISTORY_LENGTH` | `10` | Conversation history turns kept |
| `LLM_TEMPERATURE` | `0.1` | LLM sampling temperature |
| `LLM_TOP_P` | `0.3` | LLM nucleus sampling |
| `LLM_MAX_TOKENS` | `512` | LLM max response tokens |
