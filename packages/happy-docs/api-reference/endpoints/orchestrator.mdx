## Create run

```
POST /v1/orchestrator/submit
```

Create a new orchestrator run with tasks.

**Request body:**

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Run title (required) |
| `tasks` | array | Array of task definitions (1–32) |
| `tasks[].taskKey` | string | Stable key used to reference this task from other tasks' `dependsOn` |
| `tasks[].title` | string | Task title |
| `tasks[].provider` | string | `claude`, `codex`, `gemini`, or `qoder` |
| `tasks[].model` | string | Model identifier |
| `tasks[].prompt` | string | Task prompt/instruction (required) |
| `tasks[].workingDirectory` | string | Working directory path |
| `tasks[].dependsOn` | array | `taskKey` values of prerequisite tasks |
| `tasks[].retry` | object | `{ maxAttempts, backoffMs }` retry policy |
| `tasks[].target` | object | `{ type: "current_machine" \| "machine_id", machineId }` |
| `maxConcurrency` | number | Max tasks to run in parallel (1–8) |
| `mode` | string | `blocking` or `async` |
| `idempotencyKey` | string | Deduplicates repeated submissions |

## List runs

```
GET /v1/orchestrator/runs
```

List orchestrator runs for the authenticated user.

## Get run

```
GET /v1/orchestrator/runs/:runId
```

Get details of a specific run, including all tasks and their status.

**Response:**

```json
{
  "id": "clx...",
  "status": "running",
  "tasks": [
    {
      "id": "clx...",
      "prompt": "Set up database schema",
      "provider": "claude",
      "model": "claude-sonnet-4-6",
      "status": "completed",
      "dependsOn": []
    },
    {
      "id": "clx...",
      "prompt": "Write API endpoints",
      "provider": "claude",
      "model": "claude-sonnet-4-6",
      "status": "running",
      "dependsOn": ["setup-db"]
    }
  ]
}
```

## Cancel run

```
POST /v1/orchestrator/runs/:runId/cancel
```

Cancel a running orchestrator run.

## Poll for completion

```
GET /v1/orchestrator/runs/:runId/pend
```

Long-poll for run completion or status changes.

**Query parameters:**

| Field | Type | Description |
|-------|------|-------------|
| `cursor` | string | Cursor from a previous response; returns once state changes past it |
| `waitFor` | string | `change` (default) or `terminal` |
| `timeoutMs` | number | Long-poll timeout, 0–120000 (default 30000) |
| `include` | string | `summary` (default) or `all_tasks` |
