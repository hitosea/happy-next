## 桌面客户端

Happy Next 现在提供原生体验的桌面客户端，不再要求用户一直打开浏览器标签页。

- **跨平台分发**：通过 GitHub Releases 直接提供 macOS 12+ Universal、Windows x64 和 Windows ARM64 安装包
- **原生窗口生命周期**：登录状态自适应尺寸、窗口状态恢复、优化的全屏/标题栏交互、多显示器边界保护、带原生启动 Logo 的主题无闪烁启动、macOS 标题栏集成、集成式 Windows 标题栏和可靠的自定义拖动区域
- **常驻体验**：关闭到托盘、明确退出、单实例激活、可选开机启动和全局显示/隐藏快捷键
- **通知和未读状态**：干净的纯文本系统通知可可靠恢复应用并打开对应会话，隐藏窗口能够回到前台，统一的未读状态显示在程序坞或 Windows 任务栏
- **桌面控制**：原生应用菜单，以及搜索、导航、新建会话、收件箱、DooTask 和设置快捷键
- **签名自动更新**：更新包经过加密签名验证，在后台静默下载，仅在用户点击应用内更新按钮后安装
- **诊断和恢复**：脱敏桌面诊断、轮转本地日志、WebKit 存储维护、上传超时和重试处理，以及失败后保留输入内容
- **安全和媒体权限**：受限 Tauri capabilities、收紧的 CSP 与导航边界、原生上下文菜单、可靠且主题隔离的 HTML 预览子窗口、兼容 CSP 的代码编辑、系统浏览器外链，以及明确的麦克风/摄像头支持
- **平台视觉**：刷新 Logo、favicon、启动图、通知资源以及 macOS 与 Windows 独立图标，包含 macOS 26 分层图标格式和旧版 macOS 兼容回退

## 编排器

多 Agent 编排系统，定义任务依赖图并自动执行。

- **DAG 任务调度**：定义带依赖关系的任务，Happy 自动解析执行顺序并跨 Agent 调度
- **按任务模型和工作目录**：每个任务可指定特定模型和目录
- **自动审批标志**：配置编排任务的自动审批
- **会话恢复跟进**：通过会话恢复向已完成任务发送后续消息
- **可用模型 API**：`get_context` 暴露每个供应商的可用模型
- **实时监控**：活动徽章统计运行中和排队中的任务数，状态颜色进度条
- **完整 App UI**：运行列表带过滤标签和运行计数、运行详情页，以及执行历史更清晰的任务详情页
- **关联运行导航**：运行页面之间的跳转更顺畅，编排器消息可直接打开对应运行
- **级联取消**：取消运行时级联 `dependency_failed` 到依赖任务
- **MCP 工具集成**：编排器工具注册为 MCP 工具，自动填充工作目录
- **工具描述重写**：编排器重写工具描述以提升 Agent 理解
- **完整 i18n**：所有编排器 UI 完全国际化
- **CLI 自动安装**：Happy CLI 启动时安装编排器 skill 和 `/orchestrator` 斜杠命令，可直接在 CLI 里把任务并行或按依赖分发给 Claude / Codex / Gemini agent
- **`/preview-html` 内置命令**：内置 CLI 斜杠命令,生成自包含 HTML 文档并直接在 app 内预览

## 待发消息队列

CLI 繁忙时发送的消息现在会自动排队并投递。

- **服务端待发队列**：消息按会话在服务端排队
- **自动分发**：CLI 就绪时自动分发排队消息
- **队列面板 UI**：从应用中查看和管理待发消息
- **图片数量徽章**：待发消息预览显示图片附件数量
- **立即发送**：绕过队列立即发送
- **编辑与暂停/草稿**：排队消息可在发送前编辑，也可暂停或保存为草稿而不分发
- **重连同步**：WebSocket 重连时同步队列状态
- **并发安全**：强化分发并发和清理语义，分发时机经过调优（3s），避免 CLI 繁忙时丢失排队消息
- **持久化消息缓存**：会话消息存储在本地，重新打开会话时可更快显示已有历史

## 多 Agent 支持

原版 Happy 只支持 Claude Code。Happy Next 将 Claude Code、Codex 和 Gemini 视为平等的一等公民。

- **多 Agent 历史页面**，按供应商分标签页（Claude / Codex / Gemini）
- **会话恢复和复制/分叉**，支持全部三个 Agent
- **`/duplicate` 斜杠命令**：打开消息选择器，从对话中任意位置分叉会话（包括直接从 AI 回复分叉），创建一个包含截至选定消息历史的新会话，并可靠解析对应的用户消息目标
- **按 Agent 模型选择**，独立缓存，显示上下文窗口
- **模型目录新增 Claude Opus 4.8**
- **模型目录新增 Claude Fable 5**，含 1M 上下文变体，提供 low / medium / high / xhigh / max 五档推理强度
- **模型目录新增 Claude Opus 5 和 Claude Sonnet 5**，支持 1M 上下文、当前推理强度预设、快速模式能力识别和更新后的费用追踪
- **刷新 Gemini 模型目录**，加入 Gemini 3.6 Flash 和 Gemini 3.5 Flash-Lite，并保留 Gemini 3.1 Pro 与 Gemini 3.5 Flash
- **精简模型选择器**：Claude 1M 上下文变体收进单个开关（模型从 12 个减到 7 个）；宽屏下推理强度并排显示，Claude 默认 High 强度
- **Codex v0.145.0**：内置 Codex CLI 升级，刷新模型目录
- **费用追踪**，Claude 模型的精确 token 用量（缓存 token、推理 token）
- **Codex 推理强度**配置（low / medium / high / xhigh）
- **ACP（Agent Client Protocol）后端**：JSON-RPC Agent 协议（最初为 Codex 引入以替代 MCP 客户端方案，现用于 Gemini）
- **Codex App-Server 后端**：Codex 的主要后端,使用 `codex app-server` JSON-RPC 协议,通过 stdin/stdout 通信,改进会话管理和可靠性
- **Gemini 会话持久化**，JSONL 存储
- **按供应商斜杠命令**：`/clear` 全部 Agent 可用，`/compact` 仅 Claude
- **模型/模式切换**，按会话，实时元数据同步
- **Codex/Gemini diff 处理**：按文件 +N/-N 统计显示在应用中
- **消息回填**，Codex 和 Gemini 恢复/复制会话时可用
- **ACP 结果格式规范化**：Gemini ACP 结果规范化以匹配 Codex 结构
- **工具 ID 前缀回退**：不同前缀的工具 ID 回退匹配
- **Codex v2 协议修复**：解决 v2 协议字段级不兼容
- **动态权限模式**：活跃会话中通过 RPC 变更权限模式
- **Codex 上下文恢复**：`/duplicate` 使用 `thread/resume` 恢复上下文
- **工具名规范化**：`normalizeToolName` 对齐 MCP 工具名与 Codex 约定

## 语音助手（Happy Voice）

Happy Next 包含完整的语音网关栈，基于火山引擎（豆包）实时网关构建，替代此前的 LiveKit / Cartesia 方案。

- **短效 token 认证**：语音网关认证改用短效 token，安全性提升
- **火山引擎（豆包）实时网关**（`happy-voice`），通过火山 RTC AIGC + 自定义 LLM 桥统一驱动语音识别、LLM 与语音合成
- **iOS 原生通话内语音**：通话过程中流式语音合成，连接态基于房间状态变化收敛，通话激活时麦克风受保护
- **可选音色与语速**，多语言回复默认使用 seed-tts-2.0 音色
- **语音合成前的 LLM 文本清洗** 针对延迟做了优化：简单短文本跳过清洗，通话内播报本地化（i18n 措辞），限定 token 预算
- **语音设置** 经端到端加密的用户设置跨设备同步
- **麦克风静音**，支持语音对话（Happy Voice）
- **语音工具**：重构的会话管理工具（启动 / 切换 / 向会话发送消息），会话设置收敛为单一 `mode` 参数，标题更清晰，参数更稳健，会话选择器取消按钮带自动关闭倒计时
- **语音消息发送确认**，可配置倒计时
- **"思考中"指示器**，显示在语音状态栏
- **上下文感知语音**：完整应用状态（会话、git 状态等）作为结构化上下文注入
- **火山 ASR 静音/VAD 调节**，通过 `VOLC_ASR_SILENCE_MS` 环境变量调节
- **语音片段合并**，处理被中断的用户话语
- **可配置欢迎消息**，从应用设置中配置
- **系统提示工程**：英文提示、语义 XML 分隔、内联 LLM 提示
- **朗读 AI 回复**：消息底部的语音按钮合成消息文本(使用消息播放专用的火山 TTS,`VOLC_TTS_*`),采用**真流式 TTS**——边合成边播放,播放启动更快,不再中途停播或静默丢失结尾。**全局朗读队列**配合**可拖拽悬浮播放器**,可排队多条消息并在任意界面控制播放;**v2 清洗提示词带 digest 模式**,凝练长消息以获得更顺畅的朗读

## 多仓库工作树工作区

重大新功能：将多个仓库作为统一工作区管理。

- **创建工作区**，从新建会话向导中选择多个仓库
- **RepoPickerBar** 和 **RepoSelector** 组件，用于工作区创建和切换
- **按仓库设置**：分支选择（本地 + 远程）、脚本、配置
- **Git 状态聚合**，跨所有工作区仓库
- **自动生成工作区 `CLAUDE.md` 和 `AGENTS.md`**，含 `@import` 引用
- **工作区生命周期管理**：元数据追踪、git 操作、通过守护进程 RPC 归档/清理
- **工作树合并和 PR 创建**，支持目标分支选择
- **AI 驱动的 PR 代码审查**：一键启动 AI 会话审查 PR，结果发布为 GitHub PR 评论
- **路径显示**，使用 `~/` 符号代替绝对路径

## 代码浏览器和 Git 管理

应用现在包含完整的代码浏览和 git 管理体验。

- **文件浏览器**，目录导航和搜索（当前目录过滤 + 项目全局）
- **文件查看器**，Monaco 编辑器（只读模式查看、编辑模式修改）
- **提交历史**，分支选择器（本地和远程分支）
- **提交详情页**，diff 查看和操作按钮（复制哈希、复制消息）
- **Git 变更页面**：暂存、取消暂存、提交和丢弃变更
- **按文件 diff 统计**（+N/-N 行），支持 Claude Code、Codex 和 Gemini 会话
- **可点击文件路径链接**，Markdown 中支持编辑器定位
- **暂存文件 diff 显示**，精确行数统计

- **面包屑路径复制**：可直接从导航栏复制当前浏览器面包屑路径
- **批量 Git 操作加载反馈**：批量 git 操作执行期间显示加载指示器
- **Git 状态文件聚焦**：从 git 状态打开文件页时自动聚焦相关变更文件

## 会话共享

与他人通过直接邀请或公开链接分享 AI 编码会话，支持完整的端到端加密。

- **直接分享**，使用 NaCl Box 端到端加密，通过上传内容公钥实现
- **公开链接分享**，使用 token 派生密钥加密
- **访问级别**：查看、编辑和管理权限，服务端强制执行
- **实时同步**：消息、git 状态和语音聊天通过 socket 事件广播给所有共享用户
- **"全部/共享给我/我分享的"过滤标签**，会话列表中
- **共享指示器**，显示在已共享的会话上
- **分享者头像**和**发送者名称**，在共享会话中显示
- **公开分享网页查看器**，无需安装应用即可通过链接访问，消息分页加载，长共享会话打开更快
- **分享列表刷新**：分享状态变化后「我分享的」列表会更新，存在共享会话时机器标签页保持可见
- **好友个人主页显示共享会话**
- **权限感知 UI**：输入栏、语音按钮和会话操作根据访问级别自适应
- **服务端访问控制**模块，对消息、RPC 调用和语音进行权限验证
- **公开分享访问日志**

## OpenClaw 集成

通过网关系统连接外部 AI 机器，拥有独立的聊天界面。

- **机器管理**：从应用中添加、编辑和移除 OpenClaw 机器
- **两种连接模式**：Happy 中继（通过 Happy 服务器隧道）或直连 WebSocket 网关
- **Ed25519 密钥交换**，安全的机器配对
- **聊天界面**，实时流式 AI 回复、消息重试和输入指示器
- **会话管理**：创建、浏览和恢复 OpenClaw 会话
- **服务端 CRUD API**，加密元数据和乐观并发控制
- **CLI 隧道管理器**，用于中继连接

## AI 后端配置文件

通过环境变量配置文件为 Claude Code 配置替代 LLM 后端。

- **内置供应商预设**：Anthropic（默认）、DeepSeek、Z.AI、OpenAI、Azure OpenAI、Google AI
- **环境变量映射**：自动映射供应商特定的环境变量（如 `DEEPSEEK_*` → `ANTHROPIC_*`）
- **自定义配置文件**：使用任意环境变量和 `${VAR:-default}` 展开语法创建配置
- **按配置设置**：tmux 会话名称、启动脚本、默认权限模式、Agent 类型兼容性
- **配置编辑器**：全页设置 UI，用于创建和编辑配置文件

## DooTask 集成

深度集成 DooTask 项目管理，从浏览任务到启动 AI 会话。

- **任务列表页面**，过滤（项目、状态、优先级）、搜索和分页
- **任务详情页面**，HTML 内容渲染、状态工作流、负责人、文件、子任务、标签
- **实时 WebSocket 聊天**，Slack 风格布局和头像
- **聊天功能**：表情回应、语音消息回放、图片/视频消息、文件卡片
- **乐观 UI**，消息发送支持 HTTP/WebSocket 竞争
- **一键 AI 会话启动**，从任务详情（MCP 服务透传）
- **外部上下文关联**：从 DooTask 启动的会话显示上下文横幅并链接回任务
- **DooTask 连接页面**，登录、验证码支持和字段缓存
- **任务状态管理**：可点击状态徽章，支持工作流转换
- **DooTask 标签页**，主导航中集成，连接账户管理
- **创建任务和项目**，在应用内直接创建，独立表单页面
- **跨平台日期选择器**（`react-native-ui-datepicker`），底部弹窗确认
- **表单缓存**，跨页面导航保持创建表单数据
- **全局化 WebSocket 连接**：单一持久连接，实时任务更新
- **会话关联任务**：会话详情页显示关联的 DooTask 任务
- **持久化连接**：DooTask 连接通过 UserKVStore 保存到服务端
- **简单状态徽章**：无工作流的任务显示简单状态徽章

## 自托管

Happy Next 添加了一等自托管路径。

- **根目录 `docker-compose.yml`**，包含所有服务：Web 应用（Nginx）、API 服务器、语音网关、Postgres、Redis、MinIO
- **自定义服务器快捷按钮**：桌面端设置页新增快捷按钮，方便快速配置自定义服务器
